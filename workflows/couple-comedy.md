# Couple comedy production procedure

Use SYSTEM_PROMPT.md as the authority. This is a browser-operated production procedure, not an executable GitHub Action.

1. Read the request and identify the permanent reference. Default to 9:16/2D, about 30 seconds and five six-second beats; honor explicit timing.
2. Write hook → setup → escalation → reversal → punchline. Plan one principal action per beat, exact dialogue/narration, incoming/outgoing states and prop introduction. Track continuity privately with templates/scene-ledger.md.
3. Inspect the approved couple and fix the room/camera side. Keep glasses and complete consistent stick anatomy. Food never appears early simply because it is mentioned.
4. Configure visible VideoExpress settings and retained references. Review each source image before animating. Create speech through integrated available controls.
5. Submit scenes in order while earlier jobs render. Cap at five jobs or the lower visible limit. Record every job; never duplicate an unknown result.
6. Collect all successful assets, match them to the ledger and add each once to the timeline, including the final scene. Verify every addition.
7. Add correctly spelled, synchronized subtitles and suitable included music where available. Preserve complete speech and remove surplus pauses.
8. Auto Align relevant tracks, verify count/order/runtime, save and play the assembled story through.
9. Export MP4 and inspect the exported video through the end. Check joins, blank/dark sections, subtitles, audio, reference fidelity and final scene. Correct material defects within bounded retries.
10. Deliver the video with measured runtime and honest verification status. Pause only for required user action or a concrete unresolved blocker.

## Timing
Five times six seconds is a plan, not evidence of a 30-second output. Check generated durations. Shorten narration before generation when needed; do not cut or speed speech to force timing. For 36 seconds, plan six beats and queue the sixth when a slot is available.

## Review
Concurrent planning uses planned handoffs; endpoint review is not mandatory between every submission. Final playback/join checks are required attempts. If access prevents a check, label it unverified. Keep minor harmless variations; correct missing glasses, broken anatomy, early props, missing scenes or blank exports.
